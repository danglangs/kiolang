## Now

Compiled-only kio covers the whole language and every capability. Built and reviewed: the authority diff and its HTTP verbs (P1, P6, P7), grants files (P4), host-injected headers (S1), `Hmac`, `Db`, the HTTP client, and the evals E1-E4 (45 writing tasks, 55 injection twins, adaptive injections, generation cost).
